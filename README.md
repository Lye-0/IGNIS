# IGNIS

**ただ、火を見つめる。**

暗い空間の低い鉄の火床。焼けた薪の間から立ち上がる炎を、煙、火の粉、熾火、熱気、床への反射とともに鑑賞する3DのWeb作品です。表示している炎は録画や画像ではなく、その場で描画されます。

## 起動

ZIPをすべて展開し、`index.html` を通常のブラウザで開いてください。ファイルを分離したままで動く構成です。インストール、外部CDN、APIキー、ビルド、アカウントは不要です。

ファイルのプレビュー画面ではJavaScript/WebGLが実行されない場合があります。その場合は、PCの通常のブラウザか、静的配信したサイトを開いてください。ローカルサーバーでも起動できます。

```powershell
# 展開したフォルダで実行。Node.js 18以上。npm install は不要です。
npm start
```

表示された `http://localhost:5173` を開きます。別のポートを使う場合は、PowerShellで次のように指定します。

```powershell
$env:PORT = "5174"
npm start
```

WebGL 2 と `EXT_color_buffer_float` を使用します。対応機能がない場合はエラーメッセージを表示します。描画速度は端末・GPU・解像度に依存し、実機でのフレームレートは保証していません。

## 操作

| 操作 | 動作 |
|---|---|
| 「視点」＋ドラッグ／一本指 | 炎の周囲を回り込む |
| ホイール／二本指ピンチ | 近づく・離れる |
| 「気流」＋炎の近くを左右にドラッグ | 局所的に風を送り、炎と煙の流れを変える |
| 気流モードでタップ | 小さな風を送る |
| 設定 | 火勢、風、明るさ、描画品質を変更 |
| 一時停止／Space | 炎・煙・火の粉・熱気を停止／再生 |
| スピーカー | 合成した焚き火の音をオン／オフ。初期状態はオフ |
| 鑑賞モード／H | UIを隠す。右上のボタンかEscで戻る |
| R／左上のIGNIS | 視点を初期位置へ戻す |
| 矢印キー | 視点を回転 |

カメラが床の下に入らないよう、上下角度と距離を制限しています。スマートフォンも初期品質は **標準** です。端末の「視差効果を減らす」等の設定に対応する `prefers-reduced-motion` が有効な場合は、最初から一時停止します。タブが非表示になったときは描画を休止し、音をミュートします。

## 描画の仕組みと表現範囲

3Dの燃焼・煙の場をGPU上のテクスチャアトラスで保持し、上昇流、時間変化する渦、風、ポインター入力に沿って移流させています。補正付きの移流で拡散によるぼやけを抑え、細かい揺らぎを描画時にも重ねます。視線方向に体積を積分するため、視点を変えると炎の奥行きと薪による遮蔽が変わります。

HDR発光、煙による減衰、火に合わせた周囲の照明、近似的な床への反射、スクリーン空間の熱気の歪みを組み合わせています。煙は冷えて暗くなりながら上昇し、火の粉は寿命を持つ粒子として動きます。色・光量は鑑賞用に調整しています。

これは **リアリティを目指した視覚的なモデル** です。流速場は手続き的に構成しており、圧力を解く完全な流体計算、化学反応・燃焼温度の校正、薪の消耗、厳密な分光放射、光学的に厳密な熱屈折は行っていません。特定の実写と同等の画質や物理的正確さを保証するものではありません。

## テストと静的公開

```powershell
npm test
npm run build
```

`dist/` に `index.html`、`styles.css`、`src/` が出力されます。この内容を静的ホスティングの公開ディレクトリへ置けます。パスは相対指定なので、サブディレクトリへの設置にも対応します。外部ライブラリも外部フォントも同梱していません。

# IGNIS II — 火を育てる。

**ひとつ投げて、火を育てる。**

暗い空間の鉄の火床に、紙や木片を投げ入れて眺める3DのWeb作品です。初版の体積描画による炎・煙・火の粉・反射を残し、素材ごとの投げ心地、着地、着火、炭化、熾火、灰への変化を追加しました。炎も物体も動画ではなく、その場で描画しています。

## 2.1 の変更 — 「ぼうっ」と立ち上がる火

投げ入れの手応えを強めました。元のアニメーションと段階的な燃焼は維持しています。

**着地の反応と、着火の反応は別です。** 着地では既存の炎が押し動かされ、重い素材ほど熾火を散らします。素材が熱を受けて着火すると、その物の位置から炎が膨らみ、上昇流に乗って伸び、余韻を残して通常の燃焼へ戻ります。火床から離れた場所への落下では、燃え上がりを起こしません。

| 素材 | 着火時の手応え |
|---|---|
| くしゃ紙 | 素早く広がり、強めに立ち上がって短く収まる |
| 段ボール | 紙よりゆっくり、広めの炎が少し長く続く |
| 小枝 | 細めの炎が立ち上がり、火の粉がやや多く舞う |
| 木片 | 着地は重め。着火は遅く、控えめで低い燃焼音を伴い、長く熱を残す |

立ち上がりには、素材ごとの熱源・上昇流・火の粉・局所照明・床への反射・熱気の揺らぎを連動させています。音をオンにすると、映像の立ち上がりと同じ時間包絡を用いた、低い「ぼうっ」という合成音を加えます。白い全画面フラッシュやカメラシェイクは使いません。**音は引き続き初期状態ではオフ**です。

**中ボタン／右ボタンを押したままドラッグすると、どの操作モードでも視点回転**できます。左ドラッグは従来の投げる・視点・気流モードに従います。中・右ドラッグでは素材をつかんだり投げたりせず、気流モードでも風を送りません。対象は3Dの画面領域です。

## 起動

ZIPを**すべて展開**し、`index.html` を通常のブラウザで開いてください。HTML・CSS・JavaScriptを分離したまま動きます。外部CDN、APIキー、インストール、ビルド、アカウントは不要です。

チャットアプリやファイル管理アプリのプレビューではJavaScript/WebGLが実行されない場合があります。その場合はPCの通常のブラウザか、静的配信したサイトを開いてください。Node.jsがある環境では、次の方法でも起動できます。

```powershell
# 展開したIGNISフォルダで実行。Node.js 18以上。npm installは不要です。
npm start
```

表示された `http://localhost:5173` を開きます。別のポートを使う場合はPowerShellで `$env:PORT = "5174"` を設定してから起動してください。

WebGL 2と`EXT_color_buffer_float`が必要です。対応機能がない場合はエラーメッセージを表示します。描画速度は端末・GPU・解像度に依存します。

## 火に投げ入れる

素材カードをつかみ、火のある場所へドラッグして離してください。実際の立体物が持ち上がり、回転しながら飛んで火床に落ちます。カードのタップは選択だけです。選択後に火をタップするか、**「投げ入れる ↗」**を押しても投入できます。

| 素材 | 投げ心地・燃え方 |
|---|---|
| くしゃくしゃの紙 | 軽く揺れて落ち、比較的早く着火。炎が短く強まり、焦げた縁が赤く光り、穴が開き、薄い灰へ潰れていく |
| 段ボール片 | 紙より重く、板状に回転。波打つ端や表面を焦がしながら燃え、反って薄くなる |
| 乾いた小枝 | 細い枝が回転して跳ね、着火後は細い熾火と火の粉を残す |
| 割った木片 | 重めに落ちて、紙より遅く着火。木目・割れ目が炭化し、長めの燃焼と熾火を残す |

投げ込んだ瞬間に一律に炎を拡大するのではなく、物体が着地して熱を受け、着火してから、その場所の燃焼場へ熱と煙を加えます。物体を続けて入れても、火勢の増加は上限を設けて穏やかに補間しています。

同時に置ける追加素材は最大12個です。燃焼中の物体を勝手に消すことはありません。灰はしばらく残ってから小さくなって消えます。火床がいっぱいになったら、燃え尽きるのを待つか、設定の「追加した素材を片づける」を使ってください。

## その他の操作

| 操作 | 動作 |
|---|---|
| 「投げる」＋素材からドラッグ | 素材を持ち上げて投げ入れる |
| 素材を選んで火をタップ／「投げ入れる」 | 選択中の素材を投入 |
| 中ボタンドラッグ／右ボタンドラッグ | モードを切り替えずに視点回転。中ボタンの自動スクロールと画面上の右クリックメニューは抑制 |
| 「視点」＋ドラッグ／一本指 | 炎の周囲を回り込む |
| ホイール／二本指ピンチ | 近づく・離れる。ピンチに移ると持っている素材の投げ操作を中止 |
| 「気流」＋炎の近くを左右にドラッグ | 局所的に風を送り、炎と煙の流れを変える |
| 設定 | 火勢・風・明るさ・描画品質の変更、追加素材の片づけ |
| 一時停止／Space | 炎、煙、火の粉、物体の動きと燃焼をまとめて停止／再生 |
| スピーカー | 焚き火音と素材の効果音をオン／オフ。**初期状態はオフ** |
| 鑑賞モード／H | UIを隠す。右上のボタンかEscで戻る |
| 1〜4／F | 素材を選択／選択中の素材を投げる |
| R／左上のIGNIS | 視点を初期位置へ戻す |
| 矢印キー | 視点を回転 |
| Esc | 投げ操作を中止、設定を閉じる、鑑賞モードから戻る |

一時停止中に新しい素材を投げると再生を再開します。カードを選んだだけでは再開しません。画面を離れた場合やタッチ操作が中断された場合は、持っている素材の投げ操作を中止します。

スマートフォンも初期品質は**標準**です。端末の`prefers-reduced-motion`が有効な場合は最初から一時停止します。タブが非表示の間は描画を休止し、音をミュートします。鑑賞モードで隠れた操作要素はキーボードフォーカスの対象から外します。

## 表現の範囲

リアリティを目指した**鑑賞用のモデル**です。物体は簡易剛体、衝突形状は複合球・カプセル、熱は火床との近さに基づく近似です。形状の欠損・炭化・縮み・崩れは手続き的な表現で、紙の繊維破断や木片の完全な破砕を解いているわけではありません。最初から火床にある薪は消耗せず、追加した素材が消耗します。

追加素材の燃焼時間は体験向けに調整しています。着火後の主燃焼は紙が約24秒、段ボールが約40秒、小枝が約58秒、木片が約95秒を基準に、火勢・風で変わります。その後、素材ごとに熾火と灰の段階が続きます。実物の燃焼時間や温度を再現・予測する数値ではありません。

炎の流れ・光・反射・熱歪みも視覚的な近似を含みます。完全な流体ソルバー、校正済みの化学反応、厳密な分光放射や熱屈折は実装していません。

## テスト・公開・プレビュー生成

```powershell
npm test
npm run build
npm run preview:build
```

`npm run build`は`dist/`に**分離した**`index.html`・`styles.css`・`src/`を出力します。この内容を静的ホスティングへ置けます。相対パスなのでサブディレクトリにも対応します。

`npm run preview:build`だけは、共有しやすい補助用の`preview.html`を生成します。配布版の分離構成や`index.html`は変更しません。出力先を明示する場合は`node scripts/build-preview.mjs "C:\path\IGNIS-II-preview.html"`を実行します。

ブラウザテストは`python tests/browser.e2e.py`です。別途Python・Playwright・Chromiumが必要です。`IGNIS_CHROMIUM`環境変数でChromiumのパスを指定できます。GPUが使えないLinux環境ではSwiftShaderと有効なX表示環境が必要になる場合があります。検証の範囲・制約は`VERIFICATION.md`を参照してください。
